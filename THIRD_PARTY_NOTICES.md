## JavaScript and build dependencies

The [inventory](docs/licenses/npm-inventory.json) records 247 installed dependency
entries and their declared licenses, without machine paths. It was generated from
`pnpm licenses list --json` against the existing frozen lockfile on Windows. It
includes development/build tools, not just shipped browser code. Platform-specific
optional packages absent on Windows are not an artifact bill of materials.

[License texts](docs/licenses/THIRD_PARTY_LICENSES.txt) preserve the packaged license,
copyright and notice files found locally. Declared licenses include MIT, Apache-2.0,
ISC, BSD-2-Clause, BSD-3-Clause and MPL-2.0; none has missing license metadata in
this inventory. Lightning CSS/build bindings declare MPL-2.0; the source link is
[upstream Lightning CSS](https://github.com/parcel-bundler/lightningcss).

Some package archives contain declared license metadata without a separate license
file: pg-types, pgpass, rehype-katex and remark-math declare licenses in their README;
those license/copyright sections are preserved in the text collection. Stackback
declares MIT in its package metadata. Inventory references identify upstream
attribution sources. The Biome,
Rolldown and Tauri CLI platform bindings share the licensing of the matching tool;
the parent tool's packaged license/notice texts are included. Preserve appropriate
upstream attribution when distributing these tools or their outputs.

No dependencies were added or upgraded for release preparation. This is an
attribution inventory, not a claim of exhaustive legal clearance for every possible
distribution. Licenses and notices included with the actual artifact take precedence.

## Native and platform distributions

Cargo dependencies are pinned by `src-tauri/Cargo.lock`. The [native inventory](docs/licenses/native-inventory.json)
records 323 packages from locked Windows GNU / Android aarch64 metadata, including
build/test dependencies; [packaged Cargo notices](docs/licenses/NATIVE_LICENSES.txt)
retain available license/copyright texts. The [Android inventory](docs/licenses/android-inventory.json)
records 79 resolved arm64 release runtime dependencies and their published POM
license declarations (including inherited licenses); [Android notices](docs/licenses/ANDROID_LICENSES.txt)
retain license/notice texts found in the actual JAR/AAR archives.

Native resources include LICENSE, NOTICE, this document and the license inventories
and texts. Android assets are generated by `scripts/package-native-notices.mjs`;
generated copies are ignored by Git. Platform SDK/WebView/OS terms remain separate;
the JavaScript inventory alone is not a complete native SBOM or legal clearance.

Portable PostgreSQL test binaries remain third-party test tooling, are not bundled
in the browser application, and retain their upstream distribution notices.
Orivane Atlas branding files remain repository assets; generated screenshots,
databases, credentials, signing keys and private operations documents are excluded
from the public source candidate.
