# Orivane Atlas 3.2.0

- 个人任务支持直接开始、暂停和继续计时。键盘可以选择多项任务、编辑截止日期、完成任务并撤销，保存后焦点回到列表中的原任务。
- Windows 任务栏和窗口图标增加适配尺寸。缩窄窗口后导航会收起，任务仍在首屏。手机保留紧凑列表。
- 文件库支持集合间移动与恢复中断的操作，大 PDF 可按需读取原件的部分内容。笔记改进中文输入和草稿恢复，日历支持跨月键盘导航。
- 自建服务请先备份并核验恢复，再更新 Host 和配套 Web 资源，最后更新客户端。此版本沿用 3.1.14 的数据库结构。保留离线草稿、待同步操作及原件。
- 已在 Windows 原生窗口验证个人任务交互及多档内容缩放。Android 真机、Windows 跨屏 DPI、讲述人播报及已固定任务栏快捷方式升级仍待人工验证。多人协作策略另行安排。

## English

- Start, pause and resume timers directly from a task. Select tasks with the keyboard, edit due dates and undo completion. Saving returns focus to the original task.
- Windows has additional native icon sizes and a usable narrow-window layout. Phones retain the compact task list.
- Move files between collections, recover interrupted moves and preview large PDFs through range requests. Notes improve composition and draft recovery, and keyboard calendar navigation crosses month boundaries.
- For self-hosted installations, verify a restorable backup and update the Host and Web assets before clients. Preserve local drafts, pending work and originals. The database schema matches 3.1.14.
- Personal task interactions and content scaling were exercised in a native Windows window. Physical Android devices, mixed-DPI monitor transitions, Narrator speech and upgrades of pinned Windows shortcuts still need manual verification.
