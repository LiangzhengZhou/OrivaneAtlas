# 设计与实现决策

|决定|用户收益|实现成本|兼容风险|验证|
|---|---|---|---|---|
|选用测绘折页图形、纸色与深青，字标用可重复分发的路径资产|16 px 导航图标仍有轮廓，文件库和登录使用可辨识的同一品牌|重绘母版并生成各平台尺寸|Android 系统蒙版、旧图标缓存|两个实页方案、八个 ICO 尺寸、十个 Android 安全区检查；设备桌面待验|
|持久壳层使用实色，临时浮层保留分层效果|当前选区、文本和侧栏层次在卷动时一致|调整现有 CSS 层叠|高对比和平台回退|五套明暗主题，实页截图；详见 ADR0149|
|沿用既有五套偏好键、深链和命令入口|保留已选主题与常用入口|逐个修正语义色与现有组件|强制色与自选主题组合|contrast-r2.log；完整状态矩阵待验|
|在 Application 对已授权数据建立类型化资源关系索引，写入仍走原 runtime|同名 ID 或多项目引用可正确筛选，文档仍归原 Space|新增读投影和回归|委派撤权及来源适配器授权|资源投影单测；双 principal 端到端测试待补|
|资源列表每页 60 条，列表/网格偏好按服务端、workspace、principal 分区|大工作区选择和滚动更快，个人偏好不会影响其他账号|分页、视图控制和焦点返回|切换账号和最后一页数据变化|1k/10k 同机测量，三配置刷新与键盘专项|
|批量上传顺序执行，错误按文件保留并可重试|某一原件失败时其余原件可继续，降低同时占用内存|分项状态、取消待处理项和原件读取失败测试|远端提交状态仍由原上传与同步契约确定|混合 PDF/PNG/CSV，注入单项失败，重试后核对三个原件|
|日历使用单个网格 Tab 停靠点；通知支持未读过滤并显示可操作按钮|键盘用户可以连续选日期，触控用户可直接处理提醒|调整局部状态与焦点管理|跨月、筛选后目标消失|final-flows.log，三配置专项|
|区分编辑草稿、持久化与远端状态，合并并发读取，隐藏页面暂停轮询|反馈能反映用户下一步是否需要等待或重试|局部状态读取与生命周期调整|切换实体时旧结果覆盖新页面|类型与构建通过；断线/长文专项待验|

## Session 398

|决定|用户收益|成本|兼容风险与验证|
|---|---|---|---|
|本机收藏与最近打开仅保存类型化引用，按服务端、workspace、principal 分区。最近打开保留 40 条。|切换账号后只看到自己的常用资料；重新登录可继续浏览。|本地存储、跨窗口更新、与授权列表取交集。|尚无跨设备收藏同步。独立账号同名文件、原件预览、退出再登录、取消最后一个收藏的焦点均有浏览器验证。|
|批量收藏的“选择本页”只作用于当前可见页，切换页或筛选时重置。|用户能核对操作范围，避免改到筛选外的资料。|复选框、已选计数、两个幂等按钮。|不修改正式资源、文件归属和版本。三个浏览器配置覆盖加入和移除。|
|把通用文件夹作为引用集合。详情分别显示所属集合路径和它关联的空间、项目。|可以从多个项目中找到同一份资源，移除引用仍保留原文。|应用层关系索引、三种关系的副本覆盖与一次性修复。|ADR 0150、旧标记同游标修复及浏览器解除引用验证。|
|表格按文本显示，行列有界，提供源文本切换；PDF 以原页码显示提取文本；图片由既有授权原件命令和放大查看器展示。|读表格、核对 PDF 文本和放大图片均留在应用内。|浏览器处理和焦点管理；图片按需创建及释放 Blob URL。|表格不计算公式。现有 PDF 解析器仍读取完整原件。真实文件专项覆盖英文/中文及移动端。|
|日记使用工作区日期，允许直接打开指定日期。|查阅往年日记无需逐月翻页。|沿用已有 Journal 文档路由和版本契约。|闰日夹具核对原 id、版本、Markdown 和条目数。|
|相同原件仅按可见文件的有效 SHA-256 和字节数归组，分别保留条目。|可发现异名副本，同名不同字节仍独立。|对当前元数据做线性索引，不读取原件。|不合并存储或写权限关系。授权域、软删除、大小和旧摘要在单测中覆盖；实际导入三配置通过。|
|总览从授权快照中取最近三个仍可打开的引用；裸图谱深链分别引导到知识空间或项目。|可以继续阅读并理解两类图谱用途。|复用现有打开和范围选择入口，通过同一身份键隔离。|真实键盘、软删除、手机、桌面均验证；14 页外层布局跨 392 组合复验。|
|批量回收与恢复逐条检查所选版本，并按文档从属关系排序；遇到错误保留已经确认的进度。|能在回收站找回原件，也能判断部分成功后的下一步。|复用原有授权及提交入口，增加依赖顺序和状态。|不把数据批次描述为单一跨资源事务。通过混合成功/失败、父子顺序、离线工作区 CAS 与原件校验。|
|按用户请求读取 PDF 原件，在独立 Worker 解码，视口仅绘制当前一页；同时保留可选中的提取文本。|可核对图、表和排版，并以文字阅读。|复用现有 PDF.js，新增按需模块、有界画布和取消处理。|16 MiB 上限、关闭或换身份卸载、原始字节不改写；Web 和 Windows 以不同页面颜色验证。|
|用可见的集合祖先与键盘跳转入口缩短浏览路径。|无需逐次 Tab 穿过导航，可直接返回上级集合。|复用集合 ID 和可见词条，焦点返回选择器。|强制色、移动和桌面检验了焦点与 URL 保持。|
|在同一组工作区入口同时采集布局和 Chromium 的无障碍树。|读屏用户需要可发现的主区域和有名称的控件。|每次构建可在临时离线工作区重复审查，记录浏览器、语言、宽度、控件数和缺漏。|本次 14 个入口 × 2 配置共 28 项，770 次名称检查。空数据页面的结果不能覆盖弹窗、内容朗读和设备读屏体验。|
|在账号页始终显示工作区名称与服务器，把工作区、访问主体及远端 ID 放入原生可展开详情。|窄屏能更早找到登录表单，需要排查同步身份时仍可核对标识。|只调整一个 React 组件并补齐中英标签。|键盘 Enter 展开、Space 收起、焦点保留，三个配置均复验；另验证切换工作区后另一个标签仍使用原工作区。|
