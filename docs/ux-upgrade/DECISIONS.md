# 设计与实现决策

|决定|用户收益|实现成本|兼容风险|验证|
|---|---|---|---|---|
|选用测绘折页图形、纸色与深青，字标用可重复分发的路径资产|16 px 导航图标仍有轮廓，文件库和登录使用可辨识的同一品牌|重绘母版并生成各平台尺寸|Android 系统蒙版、旧图标缓存|两个实页方案、八个 ICO 尺寸、十个 Android 安全区检查；设备桌面待验|
|持久壳层使用实色，临时浮层保留分层效果|当前选区、文本和侧栏层次在卷动时一致|调整现有 CSS 层叠|高对比和平台回退|五套明暗主题，实页截图；详见 ADR0149|
|沿用既有五套偏好键、深链和命令入口|保留已选主题与常用入口|逐个修正语义色与现有组件|强制色与自选主题组合|contrast-r2.log；完整状态矩阵待验|
|在 Application 对已授权数据建立类型化资源关系索引，写入仍走原 runtime|同名 ID 或多项目引用可正确筛选，文档仍归原 Space|新增读投影和回归|委派撤权及来源适配器授权|资源投影单测；双 principal 端到端测试待补|
|资源列表每页 60 条，列表/网格偏好按服务端、workspace、principal 分区|大工作区选择和滚动更快，个人偏好不会影响其他账号|分页、视图控制和焦点返回|切换账号和最后一页数据变化|1k/10k 同机测量，三配置刷新与键盘专项|
|批量上传顺序执行，错误按文件保留并可重试|某一原件失败时其余原件可继续，降低同时占用内存|分项状态、取消待处理项和原件读取失败测试|远端提交状态仍由原上传与同步契约确定|混合 PDF/PNG/CSV，注入单项失败，重试后核对三个原件|
|日历使用单个网格 Tab 停靠点；通知支持未读过滤并显示可操作按钮|键盘用户可以连续选日期，触控用户可直接处理提醒|调整局部状态与焦点管理|跨月、筛选后目标消失|final-flows.log，三配置专项|
|区分编辑草稿、持久化与远端状态，合并并发读取，隐藏页面暂停轮询|反馈能反映用户下一步是否需要等待或重试|局部状态读取与生命周期调整|切换实体时旧结果覆盖新页面|类型与构建通过；断线/长文专项待验|
