# Session 401 · 暂停已撤权的副本与分段取页

|决定|用户收益|实现成本|兼容风险|实际验证|
|---|---|---|---|---|
|前台复核绑定会话，明确撤销后暂停工作区并要求原所有者认证|防止旧入口显示已撤权的数据，保留工作区草稿|会话订阅、React Activity、同标签锁定标记及身份校验|离线时无法获知服务端变化；既有设备资料依照原保留合同|撤销另一会话、旧深链、错误账号、所有者重登与独立编辑器草稿|
|在线只接受与原件哈希对应的 206，每段至多 256 KiB；设备原件沿用哈希验证后切片|超过文本提取上限的 PDF 可翻页，可立即退出加载|应用来源接口、Web 流长度检查、Tauri 可取消请求、PDF.js 分段加载|旧代理可能返回完整响应；单页所需数据取决于原件结构|三配置真实首尾区间、两页像素、错误响应与已挂起的请求取消|
|沿用个人工作区和细粒度凭据现有授权|撤销凭据立即影响后续请求，所有者可继续读取|真实 Host 拒绝测试与客户端身份复核|独立人类账户共享同一工作区仍需产品政策|复核 ADR0108、0124；撤销后元数据、摘录、原件拒绝及所有者原件成功|

用户主动退出（含切换账号前退出）应只处理一次远端身份，然后使用工作区目录 CAS 返回原本机工作区。被远端撤销的在线窗口在原处要求同一所有者认证；单个资源的拒绝先经会话端点复核。

集合批量移动在确认撤权后终止当前批次，重登后可继续所余成员。仅对被中止的本地工作区修订冲突有限退避；持久提交、实体版本及目标关系的前提继续由原应用服务校验。代价为持续竞争时最多额外等待 1.575 秒，其他写入维持其原重试预算。真实回执缺失和三次 60 项重开验证见 [恢复记录](evidence/session401/interrupted-collection.json)。

实施合同见 [ADR0153](../adr/0153-scoped-original-page-reads.md)。
