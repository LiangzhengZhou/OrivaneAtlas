# Orivane Atlas 3.1.9 — file library visibility

## Changes

- Navigation settings now include a File library visibility checkbox.
- Hiding it removes the standalone File library entry from the sidebar while
  keeping Files (文件) available.
- The choice is stored locally per device and survives reloads.
- Running-timer behavior from 3.1.8 remains: pause only, running tasks float to
  the top, and the card is accented.
- Project-document delete and archive-sync repairs from 3.1.7/3.1.8 remain.
