# Orivane Atlas v3.2.6

## 中文

修复笔记菜单「导出 ZIP（含图片）」生成的压缩包在标准解压工具中无法正常打开的问题。压缩包包含 UTF-8 Markdown 正文，以及正文引用的本地图片和动图原文件。升级后可重新导出此前无法解压的笔记。本次升级无需工作区数据迁移。

## English

Notes exported with **Export ZIP (with images)** can now be extracted by standard ZIP tools. The archive includes the UTF-8 Markdown file and the original local image and animation files it references. Export the note again after updating to replace an unreadable archive. No workspace migration is required.
