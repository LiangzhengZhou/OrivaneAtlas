# ADR 0153 · 文件原件分段预览与撤权

原版页面沿用文件元数据授权、原件权限、工作区绑定和内容哈希。Web 已同步且在线的原件按有界单段 Range 读取，每次携带同一强 ETag、工作区和当前会话。取件方只接受长度、范围和身份均匹配的 206。设备自己的原件及离线所有者副本沿用完整哈希校验，然后在 Blob 上切片。取消预览应停止请求并释放 PDF worker。

文本提取的 16 MiB 限额保持独立。原版查看沿用 100 MiB 文件上限、页数、绘制面积与超时限制。受权读取已交付到个人设备的数据沿用现有离线保留合同。服务端已确认失效的会话或凭据不能继续读取远端原件。在线详情在重新获得焦点或定期复核时处理明确的撤权；升级不新增跨所有者委派能力。沿用现有 schema。

收益是用户可翻阅超过提取限额的 PDF，并在读取后续数据时获得当前授权结果。实现涉及应用取件契约、连接层、PDF.js 分段输入和详情生命周期。旧 Host 或代理不支持匹配的区间响应时停止预览，保留下载操作。用合成原件核对离线切片、在线请求与撤权后复查。

已绑定且已登录的个人副本在窗口恢复焦点、回到前台和前台每 15 秒核对服务端会话。遇到明确的当前会话失效或所有者不符时暂停展示工作区，停止正在显示的详情与预览。React Activity 保留编辑状态，当前标签仅记录非凭据的锁定标记。重新认证携带预期 workspaceId 与 principalId，其他有效账号不能解锁原副本。单个文件的拒绝或移除只撤下该详情。连接故障本身不触发会话撤销。

Web 原件交易使用 Fetch AbortSignal。Tauri 通过同一 WebView 拥有的 ResourceId 取消进行中的分段请求，Rust 校验 206、ETag、长度和实际区间。关闭、退出当前原件或切换身份会释放请求。PDF.js 禁用流式预取，按最多 256 KiB 的请求获取实际所需部分；某些单页本身需要读取全部正文。
