# ADR 0013 — Orivane Atlas 工作区与个人 AI

2026-09-14；已接受并实现、验证和部署。实际结果与未完成边界见 HANDOFF/PROJECT_STATUS 和会话013；真实模型调用、自动异机备份与原生安装包不在已验证交付内。

- 展示品牌改为 Orivane Atlas；内部路径、服务、包名和数据库身份保留。原站不可变。
- Markdown 为唯一正文；CodeMirror实时预览不重写源文。笔记、日记和讲义在主区域标签页编辑，1秒停笔保存/Mod-S，IME不提交；版本冲突不覆盖，草稿默认仅内存，离开未保存内容需确认。
- 日历按本地日期打开唯一日记；空草稿不自动建库。SPACE/DOCUMENT接入同租户快照和知识关联。
- RELATED无向且允许环，REFERENCES有向；任务依赖保持DAG。图布局是个人视图，不产生业务事件。
- AI提供商属于个人；项目/空间选择个人模型，无管理员全局默认。密钥独立加密保管，普通DB只存引用。公网HTTPS出站需拒绝内网/元数据/重定向并绑定DNS检查结果。
- 发送内容前显式审批，默认AI DENY仅本次授权。结构化建议先预览后选中应用，版本/身份/路由绑定，事务落库与修订/Activity/Outbox/receipt一致；不允许Shell/任意工具/自动删除。
- 新API凭证有效期30/90/365天或null永久，默认30天；原有效期不变，改密/停用/撤销不复活。Bearer不获取供应商管理与服务器模型执行权。
- 追加v6迁移，保留v1-v5；部署前后备份及新文件恢复，凭据库单独保管。
