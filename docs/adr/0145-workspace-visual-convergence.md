# ADR 0145：工作区视觉收敛（壳层、上下文头与浮层玻璃）

日期：2026-10-26。状态：已实施（Web 样式、真实浏览器视觉矩阵与无障碍回退验证完成；生产未部署）。

## 背景

用户目标 6 要求整体视觉向现代 Claude/Codex 工作区收敛，壳层/浮层使用磨砂玻璃；目标 7 要求自动工具栏与 Atlas 主界面/浮窗。改造前壳层仍是彼此独立的纯色 Sidebar/页面、页面头滚动后脱离上下文；Atlas 浮窗与对话框遮罩未使用既有玻璃语言；自动工具栏与 Atlas 主界面/浮窗已存在但缺少与视觉系统的统一验证。

## 决策

1. **画布与壳层**：body 增加极轻的强调色/信息色径向渐变作为工作区纵深；Sidebar 使用半透明表面 + `backdrop-filter` 模糊，并保留右侧发丝线。壳层不是装饰性玻璃：仅在减少透明度/高对比/强制色/移动端降级为不透明纯色。
2. **上下文头**：`.page-header` 改为粘性（sticky）半透明带 + 模糊 + 底部发丝线，让滚动内容从下方经过；同样在减少透明度/高对比/强制色/移动端降级为纯色画布。保持原布局与按钮结构，不改变路由/交互。
3. **浮层**：Atlas 浮窗复用 `.glass-surface` 玻璃语义（带不透明回退、移动端降级、`prefers-reduced-transparency` 支持），并保留自身圆角；对话框 backdrop 统一为轻度模糊深色遮罩，在减少透明度/高对比/强制色/移动端退回纯色 `#0005`。既有 `glass.css` 的“玻璃仅用于临时浮层”原则保留，壳层玻璃仅限导航与上下文头。
4. **目标 7 现状确认**：文档编辑器已有自动/固定/隐藏工具栏（AUTO/PINNED/HIDDEN，选区出现格式工具），Atlas 主界面为对话式且不嵌入供应商表单，Atlas 浮窗可独立存在；本轮不做结构改动，仅统一浮窗视觉并重新验证。
5. **验证方式**：新增壳层计算样式用例（桌面断言 blur、移动端与 forced-colors 断言回退为 none）；沿用通知中心低铬审计与 1024/1280/1440/1920 亮暗视觉矩阵；截图保存到 `.artifacts/session308-visual`。

## 影响

- 视觉更统一：内容滚动时上下文头保持可读，侧栏与画布有连续层次；浮层/对话遮罩与既有玻璃系统一致。
- 无 API、权限、数据或路由变更；无障碍回退保持强制色/高对比/减少透明度的可读性。
- 未完成：未做像素级设计验收或用户偏好测试；暗色渐变的品牌色彩强度仍较克制；生产/真机渲染与性能未验证。
