# ADR0031 — Persisted send reservation and explicit context permission

Usage extension: adapters may report validated nonnegative input/output token counters for Chat/Responses protocols. The gateway copies these observations into the persisted attempt, including rejected responses with known consumption. Missing or invalid counters remain unknown, never zero; no currency cost is inferred. This is not a billing or monetary-budget system. The optional callback preserves older text-only adapters.

Accepted 2026-09-17. Extend the approved-run boundary, without treating it as a complete multi-provider Gateway. Before any provider side effect the Host atomically reserves one attempt on the versioned AgentRun. Reservation and connected Activity/Outbox commit together. Only the reservation owner may execute/finish. A duplicate dispatcher must not finalize another dispatcher's run. Restart interrupts unresolved runs; unknown provider outcome is never retried automatically. Attempt records expose input characters and reserved output tokens, not invented billed usage or cost.

Notes and library entries gain optional, versioned aiPolicy metadata (classification, processingBoundary, aiAccess). Missing metadata means PRIVATE/LOCAL_ONLY/DENY. Only human cookie-authenticated edits may change it; external AI edits preserve policy. Explicit ASK/ANY permits review of a cloud proposal, not automatic sends. Parent-space and document policies both apply. Evaluate trusted persisted metadata at proposal and again immediately before reservation. Approval never overrides DENY, SECRET or processing boundaries. Current HTTPS-only cloud adapters are conservatively CLOUD; no caller can label them local. Trusted-cloud exceptions and local-provider registration are not introduced here.

Fields are additive JSON payload fields in existing versioned entities; no SQL DDL change. Back up before upgrading, verify round-trip with SQLite backup/restore tests, and do not downgrade to applications that ignore the new policy. Existing documents require an explicit human permission edit before becoming AI context. Policies never alter Markdown. No expanded integration-token permissions, deployment, release, or automatic fallback.
