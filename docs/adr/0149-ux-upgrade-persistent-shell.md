# ADR 0149 · 持久导航面与临时浮层

2026-11-23。状态为开发分支已实施，设备验收待完成。修订 ADR 0145 对持久侧栏与上下文头的桌面玻璃例外。

总纲要求可预测的阅读层次、明暗主题、键盘焦点和低端设备适配。在资料浏览时导航面常驻，依赖背景模糊会使相同的文字随滚动内容改变对比。侧栏和上下文头改用主题实色，选中导航项使用标记与文字；临时弹出层继续使用既有浮层规范。保留偏好键、路由和移动降级。未引入数据格式变化。

此决策需要检查继承旧渐变、blur 的 CSS 和断言。验证使用品牌实页候选、明暗窄屏截图、五套主题语义色对比度和持久壳层样式回归。用户收益、验证与剩余风险记录在 docs/ux-upgrade/DECISIONS.md、ACCEPTANCE.md。
