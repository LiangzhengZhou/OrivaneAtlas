# ADR 0144：设置、账户与 API 的层级重排

日期：2026-10-26。状态：已实施（Web 信息架构、真实浏览器与截图验证完成；生产未部署）。

## 背景

改造前，设置页把“外观/导航/日历/通知”等偏好与“Atlas 模型、服务连接、API 凭据”混在同一个长页面的锚点导航里；账户页同时承载账户身份、工作区切换、登录会话与集成令牌。用户目标 8 要求重排设置、账户与 API 的层级关系，让偏好、账户安全、API/AI 配置各自有明确归属。

## 决策

1. **设置 = 偏好与运行环境**：导航改为分组（通用：外观/导航/日历/通知；工作区：服务器连通性/应用更新/数据与备份；账户与 API：登录会话/跨入口链接）。设置页不再渲染 Atlas 模型与提供方配置。
2. **账户 = 身份、工作区、安全**：账户页增加页签 “账户与安全” / “API 与模型”。
   - “账户与安全”：工作区与同步、登录会话、账户/密码/认领；
   - “API 与模型”：集成 API 令牌（原有创建/撤销/OpenAPI 规范）与 Atlas 模型/服务连接/预算/模型测试请求（从设置迁入同一页签）。
3. **跨入口**：设置导航“账户、API 与模型”直接切换到账户页；账户页保持现有路由与命令，不新增 API、不改变权限或服务端契约。
4. **样式**：设置导航分组标签使用弱化小标题；账户页签为圆角分段控件，移动端等宽铺满；账户页保留既有两栏内容布局。
5. **E2E 可访问性**：AI/模型配置用例改为从账户页“API 与模型”页签进入；新增层级用例并更新视觉矩阵采集位置。

## 影响

- 偏好设置页更短、职责单一；API 令牌与 AI 模型配置同处账户页，减少“设置里找 API”的歧义。
- 无数据迁移、无权限变更；既有设置深度链接仍可滚动到对应分组，账户页默认“账户与安全”。
- 未完成：账户页可进一步拆分独立“工作区”页签（本次保留在账户与安全内）；未做全局搜索到设置的跳转优化；生产/真机未验证。
