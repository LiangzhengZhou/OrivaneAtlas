# ADR 0154 · 个人阅读的原件分段校验

个人工作区的文件仍由应用服务校验身份、工作区、生命周期与父级位置。每次分段读取都在当前请求的受权事务中检查已完成的原件描述符。SQLite 和 PostgreSQL 的首次分段请求按最多 1 MiB、128 行一批扫描不可变分块，在返回内容前核对各块及整件 SHA-256。仅保留请求区间的正文。后续分段按索引选择涉及的行，重新核对读出字节与首次完整验证得到的对应摘要。完整下载沿用整件验证。

验证记录属于单个数据库实例，按工作区、原件摘要、总长和分块大小区分。最多保留 16 份、每份最多 1024 个分块摘要。历史小分块超出预算时使用分批全件验证。进程重启或记录淘汰后重新建立验证。合法离线副本、数据库 schema 和公开 HTTP 契约沿用原行为。某一未请求分块的存储损坏在读取该块或完整下载时发现。只要请求的字节不能对应已验证的原件，响应就失败。

用户收益是连续翻页减少数据库读取，冷启动也有单批内存上限。成本是两个 SQL 适配器增加索引区间读取和渐进摘要，且冷读仍需扫描整件。用同一 18 MiB 合成原件的三段 HTTP 读取、两个数据库合同、冷读及热读损坏夹具和浏览器翻页验证。多人委派依本轮用户指示暂缓。
