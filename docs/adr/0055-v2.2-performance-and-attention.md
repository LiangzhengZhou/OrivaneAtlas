# ADR 0055 — v2.2 derived indexes and attention semantics

Accepted 2026-10-04 for the user-authorized v2.2 specification.

Workspace work, task, calendar and knowledge indexes are read models derived
from authoritative workspace collections. They do not grant permissions or
replace application services. UI scope changes reuse collections; virtualized
rows preserve entity IDs and mutations keep entity version checks.

Recurrence SKIPPED means an explicit user decision for a still-open occurrence.
MISSED means its completion window expired. Skips remain separate in statistics
and are excluded from the completion-rate denominator. Expired incomplete work
uses CANCELED with RECURRENCE_WINDOW_EXPIRED and existing organization archive
metadata. No second archive model is introduced.

Reminder is a separately versioned, workspace-scoped, soft-deleted attention
entity. It shares notification planning and native schedulers, rather than
being represented by a Task. Activity/Outbox and durable WorkspaceChange records
must commit with the corresponding business mutation. Audit remains independent.

Durable workspace changes are monotonically sequenced per storage backend,
filtered by authorized workspace and cursor. Snapshot recovery is retained at
first load and invalid cursor/migration boundaries. This is authoritative server
incremental reads, not an offline replica or bidirectional synchronization.

AgentSession summaries and message pages preserve session authorization,
project/space binding, soft deletion and human approval. Performance changes do
not bypass context versions, credentials, budget, SSRF or uncertain-send safety.

Implementation and migration verification are tracked independently. This ADR
does not assert that these models have already been implemented or verified.
