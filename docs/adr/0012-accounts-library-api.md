# ADR 0012 — 账号、受限集成与学科知识空间

2026-09-14；已接受并实现，最终验证/部署状态见HANDOFF。仅本项目，自托管Node/SQLite，不迁移Sites托管或采用平台身份头。

- SQLite追加v5，旧表/Markdown原文保留。现有密钥登录兼容；持密钥的旧owner会话可一次绑定ADMIN账号，不能由第一个公网注册者取得旧库。注册创建独立workspace、PENDING账号，经管理员批准后登录；最多100账号，注册/登录限速、单并发scrypt。用户名规范化，密码12–128字符，随机盐+scrypt(N=131072,r=8,p=1)；数据库仅存不可逆密码验证器/令牌SHA256，不存可恢复凭据。
- ADMIN管理账号状态/数量看板和全库备份；不能通过普通业务接口跨租户读取。旧密钥为兼容管理员恢复通道，仍须受限保管（无自助重置密码）。停用账号删除已有会话、永久撤销API凭证；再次启用不恢复旧凭证。改密同样撤销全部会话和凭证。唯一管理员不能停用，保留1个ADMIN和最多99个USER（含待审核/停用）。
- 浏览器使用HttpOnly/Secure/SameSite会话和CSRF。集成凭证创建只显示一次、30天有效、可撤销、独立AGENT Principal；显式选择write或read-write，限定本人workspace。二者均可创建/修改/软删，写入响应可包含被操作对象，不是append-only或保密写入通道；write禁止GET批量读取，read-write额外明确授权本地客户端读取正文/历史，包括PRIVATE内容。UI展示此区别，不称“仅上传”。不触发服务器模型；AI DENY仍禁止服务器模型自动读取。禁止集成凭证管理账号/凭证、备份、调用服务器模型、执行Shell。令牌从Authorization头读取，不从URL/浏览器存储；无跨域浏览器CORS。最多20个有效未撤销凭证；过期凭证不占有效限额。
- /api/v1为版本化业务入口，沿用稳定错误码、版本检查和幂等receipt。变更事务内重新验证账号版本/会话存在/凭证状态，再查receipt；防止收请求体/密码哈希期间发生撤销仍继续写入。凭证创建、绑定和改密的键仅使用一次，重试冲突，不缓存秘密响应；公开注册要求键但以用户名唯一性去重，不回放原响应；登录/登出/备份不采用变更receipt。集成操作记录AGENT Principal；讲义来源区分HUMAN/EXTERNAL_AI，不冒充人工。
- 独立知识空间SPACE、讲义DOCUMENT，原文Markdown、修订、软删除、同workspace关系。SPACE不是任务PROJECT，不自动生成任务。图片仅受限PNG/JPEG/WebP，单图500KB、每workspace总量20MB，私有鉴权读取；小规模切片存SQLite，确保一致备份包含图片。未来大附件独立对象存储需另设备份协议。
- Markdown安全组件禁HTML执行与外部图片，支持GFM/数学公式；图片仅本项目鉴权路径。PDF使用客户端浏览器打印排版/另存PDF，不在共享服务器启动Chromium，不声称有服务器PDF生成API。
- 业务写入/修订/Activity/Outbox/receipt同事务；安全审计独立、不复制密码和正文。旧密码备份可离线攻击，因此全库备份仅管理员并须加密保管；异机备份仍需用户选接收机。
- 验证跨账号、管理员bootstrap竞争、停用/撤销、令牌动作限制、版本冲突/幂等、图片鉴权、迁移备份恢复和中英移动布局。旧v4代码不得打开v5活库；回退只恢复新文件。

## 切片边界

知识空间不进入旧NOTE/WORK关系图或/api/sync，当前需手动刷新列表；没有实时多人编辑、离线复制、嵌套目录、任意附件、LaTeX工程编译、服务端PDF、空间级分享。图像校验大小/MIME/签名，不声称完整解码或像素限制；无图片硬删/空间配额回收。修订与receipt尚无retention，管理员需关注容量（全库下载64MiB上限）。权限授予是API客户端访问授权，不是完整AgentDefinition/审批运行时。
