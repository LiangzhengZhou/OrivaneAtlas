# ADR 0151 · 通用集合成员移动

2026-11-24，开发分支。ADR 0147 和 0150 定义的 GENERAL 集合可以引用同一份笔记、文档或文件。用户从明确选中的集合移动资料时，其他集合、笔记主目录、Document.spaceId 和原件保持原有身份。

移动是一条带源关联 ID、源版本、目标目录 ID 和预期目标关联 ID（可为空）的命令。目标尚无该资源时，原关联保留 ID、增加版本并改变目录。若目标已有用户看到的同一条关联，在目标仍有效时软删源关联；目标发生并发变化则拒绝本项。禁止同目录、归档目录、非通用目录及不可用资源。服务在写事务中要求更新和解除关联两项权限，检查当前工作区。局部失败后批次停止，界面明确已确认数量。

复用现有本地事务、单效果 Outbox、CAS、重放和幂等 Receipt。SQLite 的索引列与 JSON 同步更新，原有 schema 及旧数据无需迁移。服务器须先具备 move 路由才支持新命令重放。回退前先确认待同步命令状态并保留本地副本；出现未知结果时用已有收据恢复。成本是一条新增公共写入契约及其测试，避免两个独立写入在并发或掉线时让资源失去原关联。验证覆盖目标缺失或已有、源版本变化、目标变化、重复收据、旧原件以及键盘/指针操作。
