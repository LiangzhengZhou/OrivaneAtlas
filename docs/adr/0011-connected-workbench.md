# ADR 0011 — 知识引用、受控推理与服务器权威同步

2026-09-14；已接受，切片实施与限制见会话011和PROJECT_STATUS。用户明确要求推进 AI、同步、原生、知识关联和自动异机备份。不是授权选择模型账户、备份目的地或安装大型原生工具链。

## 知识

新增显式 KnowledgeLink，端点为同工作区 NOTE/WORK 的稳定ID，关系 REFERENCES/RELATED。拒绝自链、跨工作区、已删除端点；版本化、软删除、事件/Outbox/幂等结果同事务。删除端点保留关系但查询隐藏，恢复后重新可见。全文检索是本地确定性标题/正文检索，不是 embedding；所有笔记保持 Markdown 原文和 AI DENY。双向查看入链/出链，不把任务依赖混为知识关系。

## AI 执行切片

AgentRun 保存人工输入、固定服务器模型配置摘要、审批状态、输出、错误码和版本；独立 Audit 记录状态操作，不复制输入正文。只允许人工显式输入，不自动取笔记/任务/链接正文。创建为 WAITING_APPROVAL；审批绑定运行版本和模型配置摘要；单次最多一次模型请求，无工具、Shell、SQL、委派或 fallback。网络操作在数据库事务外；先持久化 RUNNING，失败不自动重试以免重复计费，进程重启时 RUNNING 转 INTERRUPTED。每次明确审批是人工外发同意；对象 AI DENY 不能借此绕过。模型配置和凭据仅服务器受限文件，未配置时拒绝执行。不是完整自治 Agent 或规划发布系统。

预算按配置限制输入长度、输出 token、时间及并发；不将字符限制冒充精确输入 token 或费用估算。配置变化使旧审批失效，禁止重定向，限制响应大小；不允许客户端传 endpoint/key/model。输出仅供审核，不自动改业务数据。

## 同步

第一切片为服务器权威在线多设备同步：一致性 snapshot 内容摘要游标，未变化不返回正文，既有 version/幂等保护写入。客户端轮询/回前台刷新不得重置编辑草稿；明确离线/冲突状态。不称为 CRDT 或完整 LOCAL_ONLY离线双向复制，后续独立设计持久离线队列/设备撤销。

## 原生与异机备份

原生先提供明确的 server-connected Windows Tauri 配置，远端窗口不授予 IPC/系统能力；不冒充本地数据库离线客户端。编译需要 Rust/MSVC，缺失时报告阻塞，不静默安装。

备份采用用户指定第二台机器主动拉取已鉴权的在线一致性快照，先完整性检查再加密保存，保留独立恢复验证路径；凭据从受限文件读取，目标不默认推断。未指定接收机、计划和密钥保管位置时不启用定时外发。任一轮失败不能删除旧备份。所有备份只恢复至新文件，绝不覆盖活库。

## 验证

SQLite v4 只追加新表，历史SQL不变；升级前备份及新文件恢复。测试租户/版本/重复请求/端点删除、审批并发/失效/失败、恢复完整性。Windows全量检查和浏览器测试；服务器只wrapper server-safe，不运行PG/浏览器或原生编译。
