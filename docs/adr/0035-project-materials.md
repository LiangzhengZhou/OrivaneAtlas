# ADR 0035 — 项目拥有资料与文件

项目资料分为独占 OWNED 文档和 LINKED 外部资料。独占文档在项目专属知识空间中创建，正文继续由 Library 保存和修订，不转换成任务；外部引用不改变原资料的生命周期。文件作为项目拥有的版本化资料保存，下载始终鉴权并作为附件处理。

ProjectService 通过 workspace 绑定的 ProjectStore 与 LibraryStore 在同一 SQLite request 事务内执行；资料变更、活动和 outbox 原子写入。删除是可恢复软删除；删除引用不删除源文档。每个文件限制 2 MiB，以避免无界请求和内存占用。项目时间线来自任务日期，活动来自持久化资料事件和工作项活动。

SQLite 17 是追加迁移。数据库备份包含资料及文件；恢复沿用 SQLite 快照完整性验证。项目资料 API 使用现有认证、CSRF、权限和幂等键约束。外部 AI 创建的文档保留来源和默认禁止 AI 读取策略。
