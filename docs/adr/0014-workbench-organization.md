# ADR 0014：工作台整理与批量操作

日期：2026-09-14。状态：已实施，2026-09-15部署并完成迁移前后备份/新文件恢复验证。

- 任务归档独立于完成状态和软删除；归档不修改依赖，支持取消归档。
- 笔记/日记移动到同工作区命名文件夹，不改变正文、种类或日记日期。空文件夹名代表未分组；不引入跨工作区移动。
- 独立 organization 元数据以工作区/对象种类/对象ID为键并带 version。不向各 WorkItem 存储适配器塞入 UI 组织字段；SQLite v7 新增元数据、Activity/Outbox。
- 整理请求在宿主事务内调用应用服务，逐项验证实体版本和元数据版本；任何失败回滚整批。批量上限100，重复ID拒绝。删除走原软删除服务和修订/事件，幂等回执同事务。
- UI 保留失败选择；删除前确认；有未保存文档时阻止批量整理，避免关闭草稿。归档与文件夹均进入同步快照。
- 实时数学预览不改 Markdown 原文；代码不作公式，当前公式保留可编辑源文本并展示预览，离开后原位渲染。
- 数据升级前备份，升级后新文件恢复检查；未完成这些验证前不发布。
