# ADR 0010 — IP HTTPS 发布与项目日程

日期：2026-09-14。状态：已接受、实现并部署；实际验收见会话 009。

用户本轮明确授权服务器 IP 访问及继续完成产品。这更新 ADR 0008/0009 的仅隧道边界，不授权变更原站。采用独立 HTTPS 入口（已盘点 443 未占用），原 Node 宿主仍只监听回环 4317。独立 Caddy 进程、目录、资源限制与 systemd 开机服务，不修改或重载原 Nginx，不占用 80，不提供明文登录。优先申请自动续期的 IP 短期证书；失败时不静默改成 HTTP 或要求用户绕过证书验证。HTTPS 精确 Origin/Host 白名单和 Secure 会话 cookie；不信任客户端转发头。

WorkItem 新增 nullable projectId/startDate/dueDate。日期为用户选择的日历日 YYYY-MM-DD（不是 UTC 时间戳），显示按 locale；不实现时区调度或提醒。开始日不得晚于截止日。projectId 指向同工作区、未删除 PROJECT；PROJECT 自身不嵌套，完整任意层级后置。项目仍为 WorkItem，类型创建后不可更改。包含活跃成员的项目禁止删除，移出后可删除；不级联删任务。SQLite v3 / PG v2 追加迁移，既有 SQL 不改。业务更新/Activity/Outbox/receipt 同事务。

产品切片：项目进度与筛选、任务日期/月历/逾期、Markdown 文件导入为可审核草稿（不转任务）、可下载完整 SQLite 快照。备份下载仅已认证 owner，可在线生成且完整性验证，不包含访问密钥；恢复只允许到新目标，由管理员显式选择，不暴露覆盖活库端点。无需新增模型/Agent 调用。

恢复已删除任务时，若父项目也已删除，清空 projectId；不自动恢复父项目、不因项目删除而使任务无法恢复。项目当前以成员完成比例展示进度，独立项目状态编辑后置。

变更先在已校验主副本的本地验证副本编写与重型验证，再以差异核对同步服务器主副本；共享服务器只跑受限 server-safe。代码切换前做一致性备份与独立恢复验证，出错保留旧版本产物和备份，不动其他服务。
