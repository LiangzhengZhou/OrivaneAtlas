# ADR 0150 · 资源集合在本地副本中的覆盖范围

2026-11-23，开发分支。ADR 0147 定义三个不同的关联集合。服务端 bootstrap 已返回三者；当前本地 bootstrap 忽略它们，本地副本提交白名单也未包含它们。浏览器夹具在权限内建立目录、文档和项目关联后，重新载入只能看到目录和文档，筛选时没有成员。

读取与水合均沿用已有实体，类型化关联仅用于展示与筛选。资源可见性仍来自授权快照，空间与项目关联不能更改主要归属。文件夹实体和三个关联集合使用现有同步版本、事务、备份、重放和 CAS。存储 schema、远端 API 以及服务端游标格式沿用现状。

新建副本的完整快照包含这三种关联。在已有完成标记的副本上，补齐覆盖范围属于一次性、本地可重试的更新。先正常拉取增量，再依已有身份、epoch 和同一游标补关联；快照领先时保留旧标记，下轮再试。关联和覆盖标记同事务提交。在线程切换、并发变更或校验失败时沿用原有 CAS 和重试逻辑。该更新不清空本地工作区，不替换未发送的正文。

用户可在不移动文档的情况下按集合浏览并核对关联项目和空间。成本为索引构建与旧副本的一次元数据读取。验证以旧标记、pending 正文、已解绑关系、同一 ID 跨类型、同游标约束及真实浏览器重启为准。
