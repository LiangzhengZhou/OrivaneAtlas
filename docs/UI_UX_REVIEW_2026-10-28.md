# UI/UX 调整记录（2026-10-28）

状态：**规划中，暂未开工**。本文记录实机测试发现、根因判断、视觉方向与实施顺序，供后续设计与实现认领。

## 一、实机测试发现

1. 任务点击圆圈后的“确认完成”UI 会把标题挤成窄列，行高从约 72px 撑到约 238px。
   - 根因：`InlineStateConfirm` 的 `role="status"` 文本依赖 `.sr-only`，当前样式缺失，辅助文本被直接渲染。
   - 参考截图：`.artifacts/session317-task-confirm-bug.png`
2. 笔记文件夹没有整栏收起/展开按钮；只有单个文件夹的树节点箭头。
3. 整体视觉偏素，按钮、图标、卡片、标题层级不统一，缺少 Claude/现代编辑型产品的克制和质感。
4. 账户与 API 页左右两栏失衡；会话列表用大卡片堆叠，“撤销”按钮重复且抢眼；UUID/服务器地址直接占正文。
5. 侧边栏笔记/任务后的数字没有行动含义，属于视觉噪音。
6. 文件/文档仍通过 `spaceId` 绑定知识空间；没有通用的文件夹—知识空间关联；文件管理没有独立顶层区域。
7. 删除子文件夹后父文件夹仍提示“非空”。
   - 根因：`App.tsx` 的 `deleteFolder` 检查
     `folderRows.some(entry => entry.parentId === folder.id)`，
     其中 `folderRows` 包含 archived 子文件夹，未过滤。
   - 已删除文件夹仍显示在正常文件夹树的 `folder-tree-deleted` details 中，没有统一回收站。
8. 不支持文件夹/知识空间/项目自定义封面。
9. 文件夹不是可复用集合；不支持同一文档/文件链接到多个文件夹，也不支持项目/知识空间关联文件夹。

另外已记录：

- 连通性测试只检查 `/api/health` 和 `/api/account/sessions`；同步状态还依赖工作区绑定、`/api/sync`、事件流、本地 replica/outbox，因此“连通性通过但同步不可用”可能是正常的不同链路状态，不是误报。`SyncStatus` 的“重试”目前只重新加载 snapshot，不重建同步循环。
- 任务正向计时器已存在（`task-timer.tsx`）；倒计时建议做成独立的 Focus Timer，不覆盖现有正向计时。后续可做 Tauri 置顶小窗 + 托盘常驻 + 系统通知。

## 二、视觉方向：Calm Editorial

目标不是复制 Claude，而是接近“安静的编辑型知识工具”：

- 内容优先，装饰退后；减少卡片套卡片、边框、阴影和胶囊。
- 低饱和暖中性色画布 + 单一克制强调色；数据区使用稳定底色。
- 页面标题层级变轻，正文/元信息对比清楚。
- 每个区块只保留一个主按钮，其他为次级/ghost/图标按钮。
- 统一 Lucide 图标、描边粗细、尺寸和按钮高度。
- 玻璃只用于浮层、菜单、Atlas 浮窗；不要整页半透明。

### 字体与密度

- UI：Inter / system sans；正文 13–14px，元信息 12px，区块标题 14–15px，页面标题 22–24px。
- 文档阅读区可使用更适合长文的 serif/中文正文，但不强加给应用 UI。
- 行高：正文 1.55；列表行 40–44px；紧凑表格 36–40px。
- 间距：4/8/12/16/24/32；页面区块 24px，卡内 padding 16–20px。
- 圆角：按钮/输入 8px，卡片 10px，浮层 12–14px；不再使用大量超大圆角。

### 按钮与图标

- 默认文字按钮 32px 高，主按钮 36px；图标按钮 28–32px。
- 默认按钮从“白底+边框”改为低对比 ghost/soft；只有主操作用实色。
- 统一 16px 图标、1.5–1.8 描边；去掉 24px 大图标塞进小按钮的情况。
- 危险操作不默认红色实心；放在 overflow menu 或 danger zone。
- 一个区域不要出现两个视觉同权重的主按钮。

### 布局原则

- 页面顶部：标题 + 一句说明 + 右侧一个主操作；过滤/视图切换放到下一行。
- 内容列最大宽度约 1120–1200px；设置/账户页 880–960px 单列。
- 列表页优先使用行和分隔线，不用每个实体一张浮卡。
- 侧栏只做导航；统计和筛选计数不要常驻侧栏。
- 空状态、错误状态、加载状态统一为轻量 inline，不使用大面积空卡。

## 三、页面级方案

### 任务列表

- 修 `.sr-only`/确认文本导致的 238px 行高。
- 行结构改为：
  `[status] [可选确认按钮] [title minmax(0,1fr)] [meta auto]`
- 点击圆圈只进入“待确认”状态，不改变行宽/行高；显示 56–64px 的“完成”按钮，标题平滑后移 8–10px。
- 二次确认/点击外部取消；完成后可 Undo toast。
- 手机端确认按钮移到标题下方。

### 笔记页

- 文件夹面板标题加收起 chevron；收起为 40px rail，保留展开按钮。
- 状态持久化、键盘可操作；与主应用导航收起区分。
- 正常树只显示活跃文件夹；删除项进入统一回收站。
- 修复父文件夹删除判断中的 archived 子项。

### 账户与 API

- 页面改为 tabs：`账户与安全` / `同步与工作区` / `API 与模型`。
- 内容单列，最大宽度约 920px。
- 账户摘要 → 安全/会话表格 → 工作区信息（高级折叠）→ danger zone。
- 会话列表用紧凑行：设备/登录时间/到期/当前标记/行尾操作；“退出所有会话”放区块底部。
- UUID/服务器地址使用定义列表 + 复制按钮，不作为大段正文。

### 侧边栏

- 去掉笔记、任务等总量数字；只保留通知/同步异常等可行动小圆点。
- 如需数量，放在页面标题或筛选器旁。

### 文件库/知识空间/项目

- 文件库独立为顶层；文档/文件不再强制绑定知识空间，`spaceId` 作为可选上下文。
- 知识空间用于图谱/视角，不作为文件的唯一容器。
- 文件夹作为可链接集合：Folder + FolderLink（多对多），资源唯一；项目/空间可关联文件夹。
- 详见后续 ADR 和数据模型评审，不在本轮 UI 调整中直接迁移。

### 封面

- Folder/Space/Project 增加 `coverAssetId` + focal/crop 信息。
- 复用图片上传管线，禁止 Base64 入库；提供尺寸/MIME 校验和缩略图。
- 无封面时用名称派生的柔和渐变/图标；共享文件夹封面归属文件夹本身。

## 四、实施顺序

### P0：独立、低风险修复

- 任务确认 `.sr-only`/行高 bug。
- 文件夹删除判断包含 archived 子项。
- 已删除文件夹移入回收站（先做 UI/逻辑，不迁移数据模型）。
- 笔记/任务侧栏数字移除。
- 文件夹整栏收起按钮。

### P1：设计系统与高频页面

- tokens/颜色/字体/间距/圆角/按钮/图标统一。
- 任务列表、笔记页、页面头部、空状态。
- 账户与 API 页重排。
- 封面资产入口（文件夹/空间/项目）。

### P2：信息架构与集合模型

- 文件库独立。
- 回收站全类型统一。
- FolderLink 多对多、primary vs linked folder、项目/空间关联。
- 迁移旧 folderId/spaceId，补权限、同步、冲突、循环引用测试。

### P3：Focus Timer

- 任务内专注入口。
- 应用内浮窗。
- Tauri 置顶窗口 + 托盘 + 通知；退出应用后独立计时暂不做。

## 五、待确认

- 暖中性色 vs 继续冷灰；由用户/GPT 评审决定。
- 是否保留紫色为唯一强调色，或引入低饱和暖色辅助。
- 文件夹/知识空间/文件库的术语与权限模型。
- 回收站中删除文件夹时，是否默认连带子文件夹/笔记，还是要求逐项确认。
- Focus Timer 是否需要跨设备同步（建议第一版本地）。

## 六、边界

本轮**不修改产品源码**。本文只记录问题、根因和建议，等待用户/GPT 对视觉方向和集合模型确认后再进入实现。
