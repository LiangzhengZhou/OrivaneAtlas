# Orivane Atlas v2.2 Release benchmark

Measured locally on 2026-10-05 using the production Vite build, Chromium CDP and one Playwright worker. Fixture: 150 Projects, 1,500 Tasks, 3,000 Edges, 2,000 Documents, 5,000 Wiki links, 100 sessions with 1,000 messages each, 50/100KB Markdown. Fixture setup is excluded from interaction timing.

`ScriptDuration` measures JavaScript CPU; `TaskDuration` includes browser task CPU (script/layout/style). These are CPU budgets, not an end-to-end input-to-paint guarantee. Separately recorded wall time includes Playwright transport, polling and settling; it is not substituted for CPU time. Project filtering includes opening and drilling its hierarchy picker. Editor samples include 30 real key presses with CDP CPU profiling and exact save-content assertions.

Both desktop runs have 13 live List rows and 16 Board rows; the row budget is viewport plus overscan, not 1,500 mounted rows. The summary API transfers 27,771 bytes for 100 sessions and contains no message arrays; opening loads 50 recent messages, then explicitly loads 50 earlier messages. Task scope/view switches retain shared indexes, guarded by index unit tests and the runtime provider. Calendar cells use indexed day summaries; graph defaults use semantic local scope and adjacency.

Atlas list/open CPU and all wall times, sample arrays, fixture counts and mobile results are preserved in [desktop-en.json](v2.2/desktop-en.json), [desktop-zh.json](v2.2/desktop-zh.json), [mobile-zh.json](v2.2/mobile-zh.json). CPU profiles are local `.artifacts/session107-accepted-editor-{50,100}KB-{configuration}.cpuprofile`.

Reproduce after `pnpm build`: `pnpm exec playwright test --config playwright.performance.config.ts`. Avoid simultaneous compilers or other heavy suites for acceptance measurements. The test saves `.artifacts/session107-complete-benchmark-{configuration}.json`; copy accepted isolated measurements here and run `node scripts/check-v22-benchmark.mjs`. Whole-suite concurrent timings are diagnostic and do not overwrite these accepted records.

Final source measurements: .artifacts/session107-final-conversation-release-benchmark.log, three configurations passed. Benchmark tracing is disabled because DOM snapshot collection changes browser CPU samples; normal functional suites retain tracing. Picker pointer coordinates are resolved before sampling, excluding automation role-selector traversal; a trusted mouse click and visible expanded-surface assertion remain inside timing. Earlier traced/selector-inclusive diagnostic profiles are retained locally. Graph routing now mounts only the graph, and an assertion rejects a simultaneously mounted Task List. Local DAG rank layout and shared dependency adjacency/count normalization preserve scope, boundary nodes and URL behavior (15 graph/picker regressions passed).

Project focus pickers now open at the bound current Project; breadcrumbs stop at that scope. Drill-down timing moves into its real child Project and verifies that child’s tasks. Unrelated projects and external blocker tasks are not default focus candidates.
