# v2.3 release interaction benchmark

Measured locally on Windows, 2026-10-06. Baseline commit: `389b9386b84bdf99093b75a438d773d94f4ad4e2`. Sequential release-build runs used five desktop-zh samples per build with the same large fixture and interaction outcomes. Values below are median CDP ScriptDuration deltas in milliseconds; they are browser script work, not total end-to-end latency. The gate is current/baseline ≤ 1.10.

| Task tab switch | 13.368 | 6.401 | 0.479 |
| Project filter | 16.291 | 10.236 | 0.628 |
| List→Board | 19.084 | 5.358 | 0.281 |
| Calendar open | 28.697 | 10.93 | 0.381 |

| Dependency local graph | 38.168 | 21.864 | 0.573 |
| Task picker open | 3.107 | 1.64 | 0.528 |
| Task picker drill-down | 1.992 | 1.595 | 0.801 |
| Knowledge local graph | 26.227 | 15.992 | 0.61 |
| 50KB typing | 9.112 | 7.322 | 0.804 |
| 100KB typing | 7.291 | 5.895 | 0.809 |
| Atlas conversation list | 33.95 | 10.105 | 0.298 |

All 14 measured interactions pass this same-window gate. The fixture contains 150 projects, 1500 tasks, 3000 edges, 2000 documents, 5000 wiki links and 100 conversations. Live DOM rows: task list 10, task board 14, conversation list 9. The 50KB and 100KB Markdown typing cases retain content verification.

Evidence: `.artifacts/session123-current4-same-window-comparison.json`, current five raw `session123-current4-complete-benchmark-desktop-zh*.json` records, and baseline five `session123-baseline-complete-benchmark-desktop-zh*.json` records in the isolated baseline directory. Earlier failed measurements remain diagnostic evidence and are not counted as passes. This report verifies the performance gate only; complete product acceptance still requires final regression, visual and native validation.
