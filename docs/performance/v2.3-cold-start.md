# v2.3 cold-start measurements — verified local candidate

Measured on the local Windows development machine, 2026-10-05. These measurements
are evidence for transfer behavior, not complete v2.3 acceptance.

The baseline is an isolated archive of commit
`389b9386b84bdf99093b75a438d773d94f4ad4e2`, with independently installed offline
dependencies and its original host implementation. Only the measurement test was
added to that archive. The active checkout was not reset or overwritten.

Both hosts use a real SQLite database, account read credential and HTTP server.
The fixture has 150 projects, 1,500 tasks and 500 documents; document bodies are
first 1KB and then 50KB. Measurements include response receipt and JSON decoding,
without artificial network latency. Timing samples are single observations and
must not be interpreted as statistically stable latency budgets.

| Request | Baseline bytes | Current bytes |
| --- | ---: | ---: |
| Initial data, 1KB bodies | 1,711,277 | 1,217,900 |
| Initial data, 50KB bodies | 26,799,277 | 1,218,400 |
| Requested Brotli, 50KB bodies | 26,799,277 (uncompressed) | 11,486–11,488 |
| First `/api/sync`, 50KB bodies | 26,799,379 | Replaced by bootstrap |

Baseline rows measure `/api/snapshot`; current rows measure `/api/bootstrap`.
The baseline first `/api/sync` envelope is 1,711,379 bytes with 1KB bodies and
26,799,379 bytes with 50KB bodies. Shell-paint latency, simulated RTT, metadata
usability and native IPC timings still need separate measurements. The baseline
snapshot should not be described as the complete old startup traffic.

Increasing body size 50-fold grows current uncompressed bootstrap bytes by only
0.0411%. Bodies are explicitly `UNLOADED`, not empty strings. Active document
opening hydrates through the authorized body endpoint. Brotli payload decoding
is tested to equal the uncompressed payload. Native JSON now uses UTF-8; binary
responses retain Base64.

One 50KB document hydration returned 51,545 bytes in 5.11ms in the latest local
sample, with exact Markdown equality asserted. Compressed bytes vary slightly
with randomized identifiers. Repeat-run distributions remain necessary for
latency acceptance.

Reproduce current transfer measurement:

```sh
pnpm exec vitest run packages/host/src/cold-bootstrap.test.ts
```
