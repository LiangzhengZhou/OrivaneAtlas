# Orivane Atlas 3.2.1

- 笔记支持编写和直接导入单文件 HTML，可切换静态阅读、编辑源码并导出。
- 知识空间首页优先显示空间，附件较多时提供统一文件入口。文件库的项目文件夹支持搜索，成功上传的记录默认折叠，失败项可重试。
- 文件支持行内归类、批量移动和在选择目标时新建集合；笔记在更多菜单中可以直接选择主文件夹。批量上传后立即整理时，已因工作区版本变化中止的写入可自动重试。
- 此次升级沿用 v3.2.0 的存储格式。Windows 提供 x64 安装包和更新签名，Android 提供 ARM64 APK。

本地验收覆盖桌面中英文、移动中文和真实 Windows WebView2。浏览器全量首次 865/870，单元与集成首次 1593/1595，失败项均有后续定向通过记录。最终整理专项 18/18 通过。Windows 安装升级、Android 真机和讲述人实听仍待验证。
